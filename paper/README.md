# Publication package

This directory turns the frozen `word-salad` program into a reproducible
behavioral study. The central claim is deliberately narrower than the full
experimental history:

> GPT-5.6-Sol is behaviorally sensitive to coherent linguistic order embedded
> in lexically matched interference, including when aggregate word content is
> identical across paired stimuli and signal positions are uniformly random.

The core evidentiary chain is Experiments 1C, 2, the Experiment 2 tool-less
pilot, 3, and 4A. Later natural-prose and low-density studies characterize
boundaries and measurement failures; they are not prerequisites for the core
claim.

Publication-closing Experiment 6 uses a clean-validated five-symbol task before
testing only 25% and 50% signal density. The experimental phase stops after one
discovery cohort and, only if warranted, one independent replication.

## Index

- `experiment-map.md`: frozen studies, status, and manuscript role.
- `claims-and-evidence.md`: allowed claims and forbidden overstatements.
- `methods.md`: reproducible methods skeleton.
- `manuscript-outline.md`: evidence-grounded paper structure.
- `results-tables/`: machine-generated publication tables.
- `figures/`: generated publication figures and specifications.
- `statistical-analysis/`: analysis code and assumptions.
- `provenance/`: immutable tags, image hashes, and exclusions.

Raw data remain in their frozen experiment directories and are not duplicated
here.
