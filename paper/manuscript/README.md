# Manuscript drafting workspace

Drafting follows the evidence-first order:

1. `methods.md` — drafted and evidence audited;
2. `results.md` — drafted and evidence audited;
3. `figure-captions.md` — drafted;
4. Discussion — not yet drafted;
5. Introduction — not yet drafted;
6. Abstract and title — intentionally deferred.

`draft-audit.json` records the current manuscript consistency pass against
`paper-evidence-freeze-v1`. `literature-search-questions.md` defines the later
primary-literature review without prematurely committing to a mechanism.

Author, affiliation, employer-endorsement, conflict, and resource statements
remain explicit placeholders in `author-metadata.md`.
