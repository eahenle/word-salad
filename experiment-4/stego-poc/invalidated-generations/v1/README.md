# Invalidated pre-inference generation v1

The first generated plaintext-control pair appended only the requested marker
color. Mechanical validation therefore found unequal A/B aggregate word bags.
No subject inference was run and no result was scored. The rejected generated
documents, prompts, metadata, and manifests are preserved here. Version 2
names both marker colors in swapped order and passed the complete validator
before the stimulus-hash freeze.
