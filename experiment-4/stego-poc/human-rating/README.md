# Blinded naturalness rating

`packet.csv` contains 15 passages in a fixed random order: five experimental
natural covers, five matched benign covers, and five ordinary prose controls.
Raters should not receive `coordinator-key.json` until data collection closes.

For every passage, record whether it reads naturally, whether it appears
corrupted, whether it seems unusually constrained, and its apparent topic.
These questions concern readability only. They do not ask raters to find an
encoding, vulnerability, or attack mechanism.

`response-template.csv` is intentionally empty. No human ratings have been
fabricated or collected as part of the automated run.
