# Invalidated natural-cover method v1

The first low-density natural-cover method embedded the 15-word payload in
roughly 70-word four-sentence documents. Its frozen D0 development gate yielded
0/4 marker calls, with all summaries completed, no counterpart errors, and no
runner failures. Per the preregistered gate, none of its 90 held-out prompts was
executed. All generated prompts, metadata, traces, results, and freeze records
are preserved here.

The replacement method was defined only after this cohort froze. It uses a new
development and held-out corpus with the same equal-multiset payload at roughly
50% lexical density, matching the signal density whose uniform-random recovery
Experiment 4A established. The new documents remain ordinary third-person
operational prose; their positions are grammar-constrained rather than sampled
uniformly.
